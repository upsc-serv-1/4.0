**Deliverable:** Both tabs read from same data

---

### Week 2-3: Hard Notes Editor Renovation
**Goal:** Transform Hard Notes into a full editor

**What to build:**
1. **Three viewing modes**
   - Glance: Edit mode (default)
   - Focus: Read-only, serif font, minimal UI
   - Ink: Optional pencil overlay

2. **Formatting toolbar**
   - Highlight (4 colors: yellow, green, pink, blue)
   - Underline
   - Strikethrough
   - Bold/italic (optional)
   - Text color picker

3. **Inline editing**
   - Tap note → edit mode
   - Type/modify text
   - Save → update database
   - Delete with confirmation

4. **Infinite bullet list**
   - FlatList component
   - Add notes on the fly
   - Hierarchical indentation

**Deliverable:** Full editor working, can edit any note

---

### Week 3-4: Real-Time Sync
**Goal:** Changes in Hard Notes appear in Notes (and vice versa)

**What to build:**
1. **Sync Service** (`UnifiedNoteSync.ts`)
   - Edit note → save to Redux → save to DB
   - Delete note → remove from Redux → remove from DB
   - Real-time subscription to DB changes

2. **Bi-directional sync**
   - User edits in Hard Notes → Notes tab updates automatically
   - User edits in Notes tab → Hard Notes updates automatically
   - Offline support (queue edits, sync when online)

**Deliverable:** Perfectly synced tabs

---

### Week 4: Hierarchy Support
**Goal:** Support parent → child note nesting

**What to build:**
1. **Hierarchical rendering**
   - Indent children based on depth
   - Visual tree structure
   - Parent-child relationships

2. **Hierarchy management**
   - Add child note under any note
   - Move notes between parents (optional)
   - Delete parent → delete all children

**Deliverable:** Full hierarchical bullet structure

## ❓ FAQ

**Q: Will this break existing notes?**
A: No. The Supabase migration adds new columns, doesn't delete existing data. You can keep the old data and migrate gradually.

**Q: Do I need Apple Pencil support in Phase 1?**
A: No. Focus on text editing, highlighting, underlining first. Pencil is optional "ink" mode that can come later.

**Q: What about offline editing?**
A: Build it in Phase 1. Queue edits locally, sync when online. Critical for study use case.

**Q: Can I ship to App Store in 6 weeks?**
A: Yes. This is a renovation, not a new app. You already have structure. Focus on the Hard Notes editor improvements only.

**Q: What happens to Path B (Soft Notes)?**
A: Don't start it yet. Get user feedback first. In Q2 2025, you'll have real data on what features users actually want.
