## 1. EXECUTIVE SUMMARY

**Soft Notes** is a 100% pixel-perfect clone of Notability with zero compromises. Every feature, every gesture, every animation, every UI element must match Notability's current implementation (2025 version).

**Key Principles:**
- **Apple Pencil First**: Full gesture support (pressure, tilt, double-tap, hover)
- **Infinite Canvas**: Zoom, pan, rotate with hardware-accelerated rendering
- **Professional Grade**: Vector strokes, rasterization, layer-based compositing
- **Cloud Sync**: Real-time sync with offline-first architecture
- **AI Integration**: Handwriting recognition, shape detection, spell check
- **iOS Native**: Use only native iOS frameworks (no 3rd-party drawing libs except Skia for rendering)

## 5. DRAWING ENGINE - APPLE PENCIL & TOUCH

### 5.1 Pencil Input Pipeline

**Stage 1: Capture (Gesture Handler)**
```
Apple Pencil Input
  ↓
UIEvent (UIKit via RN bridge)
  ↓
Gesture Handler (raw touch + pencil attributes)
  ↓
Reanimated Shared Values (low-latency animation store)
  ↓
Worker Thread (Skia canvas render loop @ 120fps)
```

**Stage 2: Pencil Properties**
```typescript
interface PencilEvent {
  x: number;                    // Canvas-relative coordinates
  y: number;
  pressure: number;             // 0.0 - 1.0
  tilt: number;                 // 0 - 360 degrees
  angle: number;                // Rotation of pencil nib
  type: 'touch' | 'pencil' | 'mouse';
  timestamp: number;
  isPrecisionTouch: boolean;    // iPad Apple Pencil hover
  altitudeAngle: number;        // 0 - 90 degrees from vertical
}
```

### 5.2 Stroke Interpolation Algorithm

**Input:** Raw pencil points (100-120Hz)
**Output:** Smooth Bezier curve (rendered @ 120fps)

```typescript
function interpolateStroke(rawPoints: PencilEvent[]): BezierCurve[] {
  // 1. Apply pressure smoothing (3-point rolling average)
  const smoothedPressure = applyPressureSmoothing(rawPoints);
  
  // 2. Calculate velocity vector for each point
  const velocities = calculateVelocities(rawPoints);
  
  // 3. Determine stroke width based on:
  //    - User setting (pen width slider)
  //    - Pressure sensitivity
  //    - Velocity (slow = thicker, fast = thinner, for realistic effect)
  const widths = calculateDynamicWidth(
    velocities,
    rawPoints.map(p => p.pressure),
    userPenWidth,
    userPressureSensitivity
  );
  
  // 4. Create Bezier curves between consecutive triplets
  const curves: BezierCurve[] = [];
  for (let i = 0; i < rawPoints.length - 1; i++) {
    const p0 = rawPoints[Math.max(0, i - 1)];
    const p1 = rawPoints[i];
    const p2 = rawPoints[i + 1];
    
    // Catmull-Rom to Cubic Bezier conversion
    const curve = catmullRomToBezier(p0, p1, p2, widths[i]);
    curves.push(curve);
  }
  
  return curves;
}
```

### 5.3 Real-Time Rendering (Skia)

**Canvas operations (per frame, 120fps):**
1. Draw background (white/grid/texture)
2. Iterate stored strokes in Z-order
   - For each stroke: call Skia Canvas draw
   - Apply color, width, opacity, blend mode
3. Draw currently-being-drawn stroke (pressure curve)
4. Draw UI overlays (grid, selection, etc.)

**Skia integration:**
```typescript
import { Canvas, Path, Paint, Shader, Image } from '@shopify/react-native-skia';

<Canvas style={canvasStyle}>
```

### 5.4 Apple Pencil Gestures

#### Double-Tap
```
Double-tap Apple Pencil nib → trigger context menu or tool switch
```
**Implementation:**
- Monitor rapid consecutive pressure changes
- If two peaks within 300ms → register as double-tap
- Show gesture menu (erase, select, etc.)

#### Hover (iPad Pro with hover detection)
```
Pencil approaches screen (1cm away) → cursor indicator appears
```
**Implementation:**
- Monitor `UIEventTypeHover` in UITouch properties
- Show circle cursor at pencil position
- Provide preview of where stroke will land

#### Pressure Sensitivity
```
User presses harder → stroke becomes thicker
```
**Implementation:**
- Read `azimuthAngle`, `altitudeAngle` from pencil
- Calculate force using `pressure` property
- Scale pen width: `finalWidth = baseWidth * (0.5 + 1.5 * pressure)`

#### Tilt Detection
```
Pencil tilts → stroke shows angle/shading variation
```
**Implementation:**
- Read `azimuthAngle` (0-360°)
- For calligraphy tools: apply width modulation based on tilt
- Adjust opacity based on altitude angle

### 5.5 Eraser Tool

**Types:**
1. **Stroke Eraser**: Rub over strokes to erase them
2. **Shape Eraser**: Select strokes then delete
3. **Pixel Eraser**: Erase directly from rasterized image

**Implementation:**
```typescript
function handleEraserStroke(eraserPath: Path, sensitivity: number) {
  // 1. Get bounding box of eraser path
  const eraserBounds = eraserPath.getBounds();
  
  // 2. Find all strokes intersecting with eraser bounds
  const strokesToErase = strokes.filter(stroke =>
    intersects(stroke.boundingBox, eraserBounds)
  );
  
  // 3. For each stroke, determine overlap with eraser path
  //    - Use pixel-level collision detection
  //    - Calculate erased percentage
  const erasedStrokes = strokesToErase.map(stroke => {
    const remaining = eraseStrokePixels(stroke, eraserPath);
    return { ...stroke, ...remaining };
  });
  
  // 4. Delete strokes where erased > sensitivity threshold
  updateStrokes(erasedStrokes);
}
```

```typescript
function searchNotes(query: string) {
  return pages.filter(page => {
    // 1. Search in page titles
    const titleMatch = page.title?.includes(query);
    
    // 2. Search in text boxes
    const textMatch = page.textLayers?.some(t =>
      t.content.includes(query)
    );
    
    // 3. Search in OCR'd handwriting
    const handwritingMatch = page.handwritingOCR?.includes(query);
    
    // 4. Search in tags/metadata
    const metadataMatch = page.metadata?.tags?.some(t =>
      t.includes(query)
    );
    
    return titleMatch || textMatch || handwritingMatch || metadataMatch;
  });
}
```

```typescript
async function recognizeHandwriting(page: Page): Promise<TextRecognition> {
  // 1. Get all strokes as image
  const strokesImage = await renderStrokesToImage(page.strokes);
  
  // 2. Use Vision framework to recognize text
  const request = new VNRecognizeTextRequest();
  request.recognitionLanguages = ['en-US'];
  request.usesLanguageCorrection = true;
  
  const handler = new VNImageRequestHandler(strokesImage);
  await handler.perform([request]);
  
  // 3. Extract recognized text and confidence scores
  const observations = request.results;
  const recognizedText = observations.map(obs => ({
    text: obs.topCandidates(1)[0].string,
    confidence: obs.confidence,
    boundingBox: obs.boundingBox,
  }));
  
  // 4. Save OCR results for search
  await saveHandwritingOCR(page.id, recognizedText);
  
  return recognizedText;
}
```

```typescript
function detectPerfectShapes(strokes: Stroke[]): DetectedShape[] {

    // 1. Analyze stroke curvature and closedness
    const characteristics = analyzeStroke(stroke);
    
    // 2. ML classification (CoreML model)

      curvature: characteristics.curvature,
      aspectRatio: characteristics.aspectRatio,
      closedness: characteristics.isClosed,
      linearity: characteristics.linearity,
    });

    if (prediction.confidence > 0.8) {

        detectedType: prediction.type,  // 'circle', 'rectangle', 'line'
        confidence: prediction.confidence,
        suggestAutoCorrect: true,
      };
    }
    
    return null;
  }).filter(Boolean);
}
```

### 11.1 Real-Time Sync Architecture

**Architecture Pattern: CRDT (Conflict-free Replicated Data Type)**

```
┌──────────────────────────────────────────────────────┐
│ Client A (iPad)                                      │
│                                                      │
│ Local State: [Stroke 1, Stroke 2, Stroke 3]         │
│ ↓                                                    │
│ Operation Log: [ADD_STROKE_1, ADD_STROKE_2, ...]    │
│ ↓                                                    │
│ Supabase (via WebSocket)                            │
│                                                      │
│ ┌─────────────────────────────────────────────────┐ │
│ │ Server                                          │ │
│ │                                                 │ │
│ │ Merge Log:                                      │ │
│ │ [A: ADD_STROKE_1, B: ADD_STROKE_4,             │ │
│ │  A: ADD_STROKE_2, B: ADD_STROKE_5, ...]        │ │
│ │                                                 │ │
│ │ Apply order-independent resolution              │ │
│ └─────────────────────────────────────────────────┘ │
│ ↓                                                    │
│ Server pushes new ops to Client B                   │
│                                                      │
└──────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────┐
│ Client B (iPhone)                                    │
│                                                      │
│ Receives: [A: ADD_STROKE_2]                         │
│ Merges into local state → maintains consistency     │
│ State: [Stroke 1, Stroke 4, Stroke 2, Stroke 5]     │
│                                                      │
└──────────────────────────────────────────────────────┘
```

**Operation Log Example:**
```typescript

  userId: string;
  pageId: string;
  timestamp: number;
  operation:
    | { type: 'ADD_STROKE'; stroke: Stroke }
    | { type: 'DELETE_STROKE'; strokeId: string }
    | { type: 'UPDATE_STROKE'; strokeId: string; patch: Partial<Stroke> }
    | { type: 'ADD_TEXT_BOX'; textBox: TextBox }

```

### 11.2 Offline-First Sync

**Strategy:**
1. All operations saved locally to SQLite
2. Periodically attempt to sync with Supabase
3. If offline, queue operations
4. When online, merge local ops with server
5. Resolve conflicts using timestamp + user priority

**Implementation:**
```typescript
class SyncEngine {
  private localDb: SQLiteDatabase;
  private supabase: SupabaseClient;
  private syncQueue: Operation[] = [];
  private isSyncing: boolean = false;

  async addOperation(op: Operation) {
    // Save locally immediately
    await this.localDb.insert('operations', op);
    
    // Try to sync if online
    if (isNetworkConnected()) {
      this.queueSync();
    }
  }

  async sync() {
    if (this.isSyncing) return;
    this.isSyncing = true;

    try {
      // 1. Get all unsynced local ops
      const unsyncedOps = await this.localDb.query(
        'SELECT * FROM operations WHERE synced_at IS NULL'
      );

      // 2. Send to server
      const response = await this.supabase.rpc('merge_operations', {
        operations: unsyncedOps,
      });

      // 3. Apply remote ops not in local
      const remoteOps = response.data.remoteOps;
      for (const op of remoteOps) {
        await this.applyOperation(op);
        await this.localDb.insert('operations', {
          ...op,
          synced_at: Date.now(),
        });
      }

      // 4. Mark local ops as synced
      await this.localDb.update('operations', 
        { synced_at: Date.now() },
        { synced_at: null }
      );
    } finally {
      this.isSyncing = false;
    }
  }

  private async applyOperation(op: Operation) {
    const page = this.redux.pages.byId[op.pageId];
    
    switch (op.operation.type) {
      case 'ADD_STROKE':
        this.redux.dispatch(addStroke({
          pageId: op.pageId,
          stroke: op.operation.stroke,
        }));
        break;
      // ... handle other operations
    }
  }
}
```
