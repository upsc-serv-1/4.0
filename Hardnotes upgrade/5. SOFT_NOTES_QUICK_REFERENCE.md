## ⚠️ COMMON PITFALLS (AVOID!)

1. **Don't** start with shape detection before basic drawing works
2. **Don't** use Skia Text for handwriting recognition
3. **Don't** sync every single pressure point (compress!)
4. **Don't** store stroke data in Redux (too large)
5. **Don't** build UI components before data layer
6. **Don't** ignore performance until the end
7. **Don't** skip testing on real Apple Pencil hardware
8. **Don't** forget offline-first when building sync
