# Project Requirements Document (PRD)

## Project Overview

**Name:** Pilot V2 — Knowledge Vault & Notebook
**Mission:** Provide UPSC aspirants with a gorgeous, premium, iPad-optimized subject note-taking and knowledge organizer.
**Tech Stack:** React Native, Expo Router, Lucide Icons, React Native Reanimated.

---

## Functional Requirements

| FR ID | Description | User Story | Status |
| :--- | :--- | :--- | :--- |
| **FR-001** | **Dynamic Subjects Merging** | As an aspirant, I want custom topics created in the Quiz Engine to dynamically append to the left-sidebar subjects in real-time. | **MUS (Done)** |
| **FR-002** | **iPad Saving Drawer** | As an iPad user, I want saving note pop-ups to dock as full-height right drawers with comfortable 320px high editing canvases. | **MUS (Done)** |
| **FR-003** | **In-place Scrollable Subjects Sidebar** | As an aspirant, I want a single scrolling left sidebar keeping the Brand sticky while quick-nav and subjects scroll as one. | **MUS (Done)** |
| **FR-004** | **Dynamic Subject Landing Dashboard Pages** | As an aspirant, clicking a subject (like Economy) should open a dedicated subject dashboard instead of leaving a blank screen. | **MUS (Done)** |
| **FR-005** | **Butter-Smooth Notability Physics Layout Animation** | As an aspirant, I want subtopics to expand and collapse inline with smooth spring-physics fades instead of jerky box snaps. | **MUS (Prepared)** |
| **FR-006** | **Syllabus Tracker Viewport Dimension Edge Fade** | As an aspirant, I want scrolling items near the top/bottom edges of the ScrollView to fade elegantly into another dimension. | **Future (Prepared)** |
| **FR-007** | **Context-Aware Floating AI Chat Card (Option 3)** | As an aspirant, I want a floating draggable chat card that adapts its AI agent persona, prompt context, and tools automatically based on the active screen (Quiz, PYQ, Analysis). | **MUS (Prepared)** |
| **FR-008** | **Auto-Minimize on Modal Overlaps** | As an aspirant, I want the floating AI chat to automatically minimize into a bottom-right Brain FAB whenever another sheet or popup (like Save) is opened, preventing overlay clutter. | **MUS (Prepared)** |
