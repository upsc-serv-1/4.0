# [FR-001] Subject Performance Breakdown

## Labels
`MUS`, `analytics`, `core`

## User Story
As a student, I want to see how many questions were correct/incorrect/skipped per subject, so I can see which major subject needs work.

## Proposed Solution

### Overview
Add a list/grid view to the Analytics report that shows each subject with its corresponding Correct, Incorrect, and Skipped counts.

### Implementation Flow
1. Aggregate results from `questions` array by `subject`.
2. Map counts: `isCorrect`, `isIncorrect`, `isSkipped`.
3. Render as a summary card above the detailed breakdown.

### Acceptance Criteria
- [x] Shows list of all subjects in the test. ✅ Completed
- [x] Displays exact counts for Correct, Incorrect, and Skipped. ✅ Completed
- [x] Color-coded status (Success/Error/Tertiary). ✅ Completed
