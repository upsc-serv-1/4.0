# [FR-001] Core Responsive Infrastructure

## Labels
`MUS`, `enhancement`, `core`, `responsive`

## User Story
As an aspirant, I want consistent layouts across devices so that the app reacts optimally to whatever screen size I am using.

## Proposed Solution

### Overview
Create a unified Responsive Infrastructure using standard breakpoints and scaled sizing for React Native. This avoids hardcoded device checks scattered across components.

### Implementation Flow
1. Create `src/hooks/useResponsive.ts` or `src/utils/responsive.ts`.
2. Define standard breakpoints:
   - `isSmallPhone`: width < 375px
   - `isPhone`: width >= 375px && width < 768px
   - `isTablet`: width >= 768px
   - `isLargeTablet`: width >= 1024px
3. Implement a standard scale utility `scaleSize(base: number)` based on the screen's width relative to a standard 375px mockup width, clamped to prevent absurd sizes on iPad.

### Technical Approach

```typescript
// src/hooks/useResponsive.ts
import { useWindowDimensions, Platform } from 'react-native';

export function useResponsive() {
  const { width, height } = useWindowDimensions();
  
  const isSmallPhone = width < 375;
  const isTablet = width >= 768;
  const isLargeTablet = width >= 1024;
  const isIOS = Platform.OS === 'ios';
  const isAndroid = Platform.OS === 'android';
  
  // Proportional scaling base
  const scaleFactor = isTablet ? 1.2 : isSmallPhone ? 0.9 : 1.0;
  
  const getResponsiveValue = <T>(values: { phone: T; tablet: T; smallPhone?: T }): T => {
    if (isTablet) return values.tablet;
    if (isSmallPhone && values.smallPhone !== undefined) return values.smallPhone;
    return values.phone;
  };

  return {
    width,
    height,
    isSmallPhone,
    isTablet,
    isLargeTablet,
    isIOS,
    isAndroid,
    scaleFactor,
    getResponsiveValue,
  };
}
```

### Key Considerations
- Avoid recalculating scale metrics on every render frame unless `useWindowDimensions()` notifies changes (e.g., device rotation).
- Tablet scale factor should be capped so that UI components don't become huge.

## Acceptance Criteria

- [ ] `useResponsive.ts` hook created and tested.
- [ ] Dynamic width checks react to device orientation changes (if enabled).
- [ ] Baseline padding/margins scale properly via `scaleFactor`.
