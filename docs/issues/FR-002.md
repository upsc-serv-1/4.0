# [FR-002] Content Containment & Max Widths

## Labels
`MUS`, `enhancement`, `ui`, `tablet`

## User Story
As a tablet user, I want readable, centered layouts with logical max-widths instead of stretched content across 1000px+.

## Proposed Solution

### Overview
Introduce a standard `MaxWidthContainer` or enhance `PageWrapper` to constrain content width on iPads and large tablets. Text blocks and lists should not span the entire landscape orientation of an iPad Pro.

### Implementation Flow
1. Modify `src/components/PageWrapper.tsx` or create `src/components/MaxContentWidth.tsx`.
2. Add a standard maximum content width variable (e.g., `MAX_CONTENT_WIDTH = 720` or `840`).
3. Use standard horizontal padding that dynamically expands when the screen is wider than the maximum content width, maintaining center alignment.

### Technical Approach

```typescript
// src/components/PageWrapper.tsx update or utility
import React from 'react';
import { View, StyleSheet, useWindowDimensions } from 'react-native';

export const PageWrapper = ({ children, style }: any) => {
  const { width } = useWindowDimensions();
  const isTablet = width >= 768;
  
  // Maximum width for content container to maintain reading density
  const contentWidth = isTablet ? Math.min(width * 0.85, 800) : '100%';

  return (
    <View style={styles.root}>
      <View style={[
        styles.inner,
        isTablet && {
          alignSelf: 'center',
          width: contentWidth,
        },
        style
      ]}>
        {children}
      </View>
    </View>
  );
};
```

### Key Considerations
- Header and Background backgrounds should still bleed to the edge of the screen.
- The content container itself should hold the margins/padding.
- Screens with specialized infinite canvas (like PilotV2 Glance View) should have their own frozen layout logic instead of this global containment.

## Acceptance Criteria

- [ ] Global screens (`app/profile.tsx`, settings, tracker) don't span infinite horizontal width on iPad.
- [ ] Text blocks are constrained to readable line lengths.
- [ ] Centered content container respects user theme and alignment on tablet.
