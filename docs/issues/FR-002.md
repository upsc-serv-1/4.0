# [FR-002] Section Group Performance Breakdown

## Labels
`MUS`, `analytics`, `detail`

## User Story
As a student, I want to see the count of errors at the Section Group level (e.g. Modern History vs Ancient), so I can narrow down my study focus.

## Proposed Solution

### Overview
Expand the subject view to show "Section Groups" (Themes) within each subject.

### Implementation Flow
1. Within each subject, group questions by `section_group`.
2. Calculate Correct/Incorrect/Skipped counts for each section group.
3. Render as sub-items with a Stacked Bar Meter showing the status breakdown.

### Acceptance Criteria
- [x] Breaks down subjects into their constituent Section Groups. ✅ Completed
- [x] Shows counts for each section group. ✅ Completed
- [x] Visual indicator (Stacked Bar) for quick scanning. ✅ Completed
