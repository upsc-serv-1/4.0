# [FR-003] Microtopic Error Analysis

## Labels
`MUS`, `analytics`, `precision`

## User Story
As a student, I want to see exactly which microtopics (e.g. Article 370, Quit India Movement) I am consistently failing, with specific question counts.

## Proposed Solution

### Overview
The deepest level of the breakdown showing individual microtopics and their performance.

### Implementation Flow
1. Group questions by `micro_topic`.
2. List microtopics with highest error counts at the top of the "Weak Areas" section.
3. Show total questions per microtopic vs number of errors.

### Acceptance Criteria
- [x] Lists specific microtopics. ✅ Completed
- [x] Shows "Errors / Total" (e.g. 3/5 missed). ✅ Completed
- [x] Links to "Review" for those specific questions. ✅ Completed
