# [FR-003] Adaptive Grids & Layout Reflow

## Labels
`MUS`, `enhancement`, `ui`, `grid`

## User Story
As a user, I want lists to automatically reflow into multi-column grids on bigger screens and stack vertically on narrow screens.

## Proposed Solution

### Overview
Instead of scaling items linearly, use a standard adaptive column reflow system. E.g. a single-column button stack on iPhone becomes a 2-column button grid on iPad. Similarly, settings rows or dashboard stats cards can take advantage of the wider width.

### Implementation Flow
1. Identify key screens: Profile page settings items, Analytics cards, Dashboard lists.
2. Replace standard vertical rendering with dynamic flexWrap or FlatList `numColumns` based on `isTablet`.
3. Handle FlatList state reloading when orientation/columns change dynamically.

### Technical Approach

```typescript
// Profile settings cards adaptive reflow
const numColumns = isTablet ? 2 : 1;

// Inside Component
<View style={{ 
  flexDirection: isTablet ? 'row' : 'column', 
  flexWrap: 'wrap',
  gap: 16,
}}>
  {items.map(item => (
    <View style={{ 
      width: isTablet ? '48%' : '100%', 
    }}>
      <CardItem {...item} />
    </View>
  ))}
</View>
```

### Key Considerations
- React Native `FlatList` requires a changing `key` prop (e.g., `key={isTablet ? 'table' : 'phone'}`) if you dynamically change the `numColumns` prop at runtime.
- Space distribution (`gap` or percentage widths) must account for standard layout scaling.

## Acceptance Criteria

- [ ] Settings rows or preference cards reflow dynamically on tablet screens.
- [ ] Grid items have consistent sizing and don't overlap.
- [ ] Horizontal padding scales proportionally.
