# [FR-004] Modals & Bottom Sheets Scaling

## Labels
`MUS`, `enhancement`, `ui`, `modal`

## User Story
As a tablet user, I want overlays to appear centered with a maxWidth (like page sheets) rather than taking over the whole bottom.

## Proposed Solution

### Overview
Standardize Modal, AnalysisExportSheet, and other sheet layouts. On phones, they use full-width bottom sheets (`justifyContent: 'flex-end'`). On tablets, they should be centered modal cards (`justifyContent: 'center', alignItems: 'center'`) with a max width.

### Implementation Flow
1. Refactor components like `AnalysisExportSheet.tsx` and `MyVitaminEditorSheet.tsx` styles.
2. In the overlay styles, dynamically set `justifyContent` and `alignItems`.
3. Constrain the sheet width on tablet using a max width (e.g. `width: isTablet ? 540 : '100%'`) and appropriate border radii.

### Technical Approach

```typescript
// Modifying standard overlay & sheet styles
const sheetStyles = (isTablet: boolean, colors: any) => StyleSheet.create({
  overlay: {
    flex: 1,
    backgroundColor: 'rgba(0,0,0,0.5)',
    justifyContent: isTablet ? 'center' : 'flex-end',
    alignItems: isTablet ? 'center' : 'stretch',
    padding: isTablet ? 40 : 0,
  },
  sheet: {
    width: isTablet ? 540 : '100%',
    borderRadius: isTablet ? 24 : undefined,
    borderTopLeftRadius: 28,
    borderTopRightRadius: 28,
    // Bottom radius only needed on tablet where sheet floats
    borderBottomLeftRadius: isTablet ? 28 : 0,
    borderBottomRightRadius: isTablet ? 28 : 0,
    maxHeight: isTablet ? '85%' : '92%',
  },
});
```

### Key Considerations
- Centered modals on iPad feel premium and desktop-class.
- Backdrop touches should still correctly trigger `onClose`.
- Keyboard avoids (`KeyboardAvoidingView`) inside centered modals must behave correctly.

## Acceptance Criteria

- [ ] `AnalysisExportSheet` is centered with max width on iPad.
- [ ] Sheet items don't stretch to absurd horizontal widths on tablet.
- [ ] Modals still use bottom-docking on all phones (iOS/Android).
