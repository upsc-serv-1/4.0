# [FR-004] Hierarchical Analytics Navigation

## Labels
`MUS`, `ui`, `navigation`

## User Story
As a student, I want a nested view that lets me drill down from Subject -> Section Group -> Microtopic with error counts at each level.

## Proposed Solution

### Overview
A collapsible tree-like structure for the "Analysis" tab in the result screen.

### Implementation Flow
1. Create a `HierarchicalBreakdown` component.
2. Use accordion/collapsible sections for each level.
3. Show summary counts on the collapsed header and detail on expansion.

### Acceptance Criteria
- [x] Smooth expansion/collapsing. ✅ Completed
- [x] Summarized counts always visible at higher levels. ✅ Completed
- [x] No performance lag with 100+ questions. ✅ Completed
