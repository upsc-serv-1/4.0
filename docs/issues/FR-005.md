# [FR-005] Visual Performance Meters (Stacked Bars)

## Labels
`MUS`, `ui`, `ux`

## User Story
As a student, I want to see color-coded stacked bars representing Correct/Incorrect/Skipped counts for each category.

## Proposed Solution

### Overview
Add a visual component `StatusMeter` to each row in the breakdown.

### Implementation Flow
1. Create a `StatusMeter` that takes `{ correct, incorrect, skipped }`.
2. Render a single horizontal bar split by percentage of each status.
3. Use `colors.success`, `colors.error`, and `colors.textTertiary`.

### Acceptance Criteria
- [x] Meter segments proportional to counts. ✅ Completed
- [x] Tooltip or label showing exact numbers. ✅ Completed
- [x] Premium look with rounded corners. ✅ Completed
