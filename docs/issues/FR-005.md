# [FR-005] Butter-Smooth Notability Physics Layout Animation

## Labels
`MUS`, `enhancement`, `ui-ux-animation`

## User Story
As an aspirant, I want subtopics to expand and collapse inline with smooth spring-physics fades instead of jerky box snaps, so that using the sidebar feels incredibly satisfying, continuous, and premium like Apple's native elements.

---

## Proposed Solution

### Overview
Transition the inline expandable subtopics in `PilotV2Sidebar.tsx` from standard native LayoutAnimations to a GPU-accelerated **React Native Reanimated** wrapper. This wrapper dynamically springs the height, opacity, and vertical translation (`translateY`) of the expanded containers.

### Implementation Flow
1. **Scaffold Animated Wrapper**: Build an `<InlineCollapsible>` component inside `PilotV2Sidebar.tsx`.
2. **Setup Shared Values**: Allocate a `progress` shared value initialized with `withSpring` representing `0` (collapsed) to `1` (expanded).
3. **GPU Interpolation Styles**: Define an `animatedStyle` that interpolates:
   - `height` from `0` to the content height.
   - `opacity` from `0` to `1` (soft quadratic fade).
   - `translateY` from `-12px` to `0px` (sliding down organically).
4. **Integration**: Swap the static `{isSelectedSubject && (...)` condition in the sidebar map with the animated `<InlineCollapsible>` container.

### Technical Approach (Reanimated Pattern)
```typescript
import Animated, { useSharedValue, useAnimatedStyle, withSpring } from 'react-native-reanimated';

export function InlineCollapsible({ isExpanded, children }) {
  const progress = useSharedValue(isExpanded ? 1 : 0);
  
  React.useEffect(() => {
    progress.value = withSpring(isExpanded ? 1 : 0, { damping: 16 });
  }, [isExpanded]);
  
  const animatedStyle = useAnimatedStyle(() => ({
    height: progress.value * 180, // or dynamically measured height
    opacity: progress.value,
    transform: [{ translateY: (1 - progress.value) * -12 }],
  }));
  
  return <Animated.View style={animatedStyle}>{children}</Animated.View>;
}
```

## Acceptance Criteria
- [ ] Subtopics expand and collapse with custom spring physics instead of snapping immediately.
- [ ] Subtopics fade into view smoothly from opacity `0` to `1` as they open.
- [ ] Subtopics slide downwards by `12px` organically, creating a dimensional emergence effect.
- [ ] Clicking on different subjects (like Economy or History) smoothly collapses the previous active subject and slides down siblings with zero jerky frame-drops.
