# [FR-005] Proportional Typography & Touch Targets

## Labels
`MUS`, `bugfix`, `ui`, `typography`

## User Story
As a small phone user, I want buttons not to overlap and text to fit neatly without clipping or cluttered overlapping.

## Proposed Solution

### Overview
Prevent UI breakage on small phones (e.g. iPhone SE, small Androids) by adding dynamic text clamping or slightly smaller scaled fonts, and ensuring button flex-layouts support horizontal wrap where needed.

### Implementation Flow
1. Audit `app/profile.tsx`, Glance View FABs, and standard forms.
2. Add dynamic font sizes that clamp based on screen width.
3. Ensure horizontal action bars (`flexDirection: 'row'`) wrap or become scrollable if the buttons exceed screen width on a small phone.
4. Fix the `avatarList` in profile.tsx and similar chips scrollable lists to not cut off.

### Technical Approach

```typescript
// Dynamic font clamping helper
export const getClampedFontSize = (baseSize: number, width: number) => {
  if (width < 360) {
    // Small phone adjustment (-10%)
    return baseSize * 0.9;
  }
  if (width >= 768) {
    // Tablet adjustment (+15%)
    return baseSize * 1.15;
  }
  return baseSize;
};

// Style application
title: {
  fontSize: getClampedFontSize(20, width),
  // Ensure accessible minimum tap height for small phone users
  minHeight: 44, 
}
```

### Key Considerations
- Never allow dynamic scaling to go below readable limits (min font size 11px for captions, 14px for body text).
- Provide adequate horizontal padding even on narrow screens (minimum 12-16px).

## Acceptance Criteria

- [ ] Large page titles (`h1: 36`) scale down slightly on small phones to prevent wrapping to 3 lines.
- [ ] Side-by-side action buttons on small screens stack or reflow instead of clipping.
- [ ] Minimum touch targets are maintained at 44x44 dp.
