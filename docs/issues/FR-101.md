# [FR-101] Interactive Option Selection in Review Mode

## Labels
`MUS`, `enhancement`, `analytics`

## User Story
As a student revising my tests, I want to be able to click options on the question cards in the analysis report so that I can "re-attempt" the question and check if I still remember the concepts.

## Proposed Solution

### Overview
Modify `SharedQuestionCard.tsx` to enable option selection even when in "review" or "learning" mode.

### Implementation Flow
1. Identify the condition that currently disables clicks in review mode.
2. Update the `onOptionSelect` handler to support a "volatile" selection state that doesn't save to the database but provides visual feedback.
3. Ensure the selection animation plays for the new user choice.

### Technical Approach

```typescript
// SharedQuestionCard.tsx
const [localSelection, setLocalSelection] = useState<string | null>(null);

const handlePress = (opt: string) => {
  setLocalSelection(opt); // Temporary selection for practice
};
```
