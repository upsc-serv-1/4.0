# [FR-102] Master "Show My Mistakes" Toggle

## Labels
`MUS`, `ui`, `ux`, `analytics`

## User Story
As a student, I want to hide my previous answers so I can re-attempt the question objectively. I then want to toggle them back on to see exactly where I went wrong (Red/Green/Gray).

## Proposed Solution

### Overview
Add a sticky or header-based toggle switch in `ReviewSection.tsx` that controls the `showMistakes` mode globally for all cards.

### Implementation Flow
1. Add `useState([showMistakes, setShowMistakes])` in `ReviewSection.tsx`.
2. Add a `Switch` or custom `ToggleButton` component at the top of the list.
3. Pass `showMistakes` as a prop to every `SharedQuestionCard`.

### Technical Approach

```tsx
// ReviewSection.tsx
<View style={styles.toggleRow}>
  <Text>Show My Mistakes</Text>
  <Switch value={showMistakes} onValueChange={setShowMistakes} />
</View>
```
