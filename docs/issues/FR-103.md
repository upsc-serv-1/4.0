# [FR-103] Historical Accuracy Indicators (Red/Green/Gray)

## Labels
`MUS`, `ui`, `feedback`

## User Story
As a user, when I turn the "Mistakes" toggle ON, I want to see my previous answer in Red if wrong, and the correct answer in Green. If I skipped it, I want a Gray "Skipped" badge so I know I didn't attempt it.

## Proposed Solution

### Overview
Enhance the styling logic in `SharedQuestionCard` to respond to the `showMistakes` prop.

### Implementation Flow
1. If `showMistakes` is true:
   - Match `selectedAnswer` against `correctAnswer`.
   - Apply `colors.error` (Red) to the wrong choice.
   - Apply `colors.success` (Green) to the correct choice.
   - If `!selectedAnswer`, show a `Gray Chip` with the text "SKIPPED".
2. If `showMistakes` is false:
   - Hide all correct/incorrect highlighting.
   - Hide the "Skipped" badge.

### Technical Approach

```tsx
// SharedQuestionCard.tsx
const isCorrect = item.selectedAnswer === item.correctAnswer;
const wasSkipped = !item.selectedAnswer;

{showMistakes && wasSkipped && (
  <View style={styles.skippedBadge}>
    <Text>SKIPPED</Text>
  </View>
)}
```
