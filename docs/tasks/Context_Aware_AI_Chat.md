## 📋 Requirements

### Functional Requirements
* **[REQ-001] Dynamic Theme Styling (Flashcard Aesthetics)**:
  - Match the exact border-radius (`24px`) and premium card border styling of the Flashcard Popup.
  - Dynamically read current theme colors (`colors.surface`, `colors.border`, `colors.textPrimary`) so the card background, border, and text swap instantly between light and dark modes on theme change.
* **[REQ-002] Top-Anchored Chat Input**:
  - Place the AI chat input text box at the very top of the card (directly beneath the header) rather than the bottom, keeping it entirely clear of the keyboard when it rises.
* **[REQ-003] Keyboard-Responsive Height Scaling**:
  - Register Native Keyboard listeners (`Keyboard.addListener`) to dynamically calculate the card's active height on keyboard show/hide, shrinking the card smoothly on the GPU so it perfectly clears the keyboard.
* **[REQ-004] Context-Aware System Agents**:
  - Automatically detect the current active screen state (Quiz, Analysis, PYQ, Notes) and dynamically inject question data, test history, or markdown contents into the active AI system prompt.
* **[REQ-005] Auto-Minimize on Modal Overlaps**:
  - Whenever another sheet or popup (such as the Save Sheet) opens, automatically morph the chat card into a compact `64px x 64px` floating Brain FAB at the bottom right. Dismissing the modal automatically re-expands the card.
